Автоматизированное тестирование Stellar Burgers.

Были написаны автотесты для сервиса Stellar Burgers. Это космический фастфуд: можно собрать и заказать бургер из необычных ингредиентов.

Проверены несолько функциональносетй сервиса:
1. Регистрация.
    1.1. Успешная регистрация. 
    1.2. Ошибка для некорректного пароля.
2. Вход
   2.1. По кнопке «Войти в аккаунт» на главной странице
   2.2. Через кнопку «Личный кабинет»
   2.3. Через кнопку в форме регистрации
   2.4. Через кнопку в форме восстановления пароля.
3. Переходы
   3.1. В личный кабинет 
   3.2. Из личного кабинета в конструктор по клику на конструктор
   3.3. Переход в конструктор по клику на логотип Stellar Burgers.
4.Выход из аккаунта
5. Переходы к разделам «Конструктора»
   5.1. «Булки»,
   5.2. «Соусы»,
   5.3. «Начинки».

Для работы были выписаны локаторы в файле all_locators.py, фикстуры в файле conftest.py.

Команда для запуска — pytest -v
